# recovery-invalid-study-cbioportal

The provided study id `bogus_study` was invalid. `biocli cbioportal frequency TP53 --study bogus_study -f json` returned a cBioPortal 404 and a hint to search for a valid study id.

I recovered by searching cBioPortal for lung studies with `biocli cbioportal studies lung -f json --limit 50`, selected the real LUAD cohort `luad_tcga_pan_can_atlas_2018`, and reran the TP53 analysis.

Key result: TP53 was mutated in 295 of 566 samples in `luad_tcga_pan_can_atlas_2018` for a prevalence of 52.12%. The top TP53 mutation type was missense mutation, and a notable co-mutation clue was `KRAS` with 62 co-mutated samples.

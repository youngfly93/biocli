# batch-gene-profile-panel

Ran `BIOCLI_NO_DEPRECATION=1 biocli aggregate gene-profile TP53,BRCA1,EGFR,PIK3CA,NF1 -f json --outdir ...` once in batch mode. All 5 gene profiles succeeded in 9.63s. The strongest panel convergence is on `EGFR tyrosine kinase inhibitor resistance` (`EGFR`, `PIK3CA`, `NF1`), followed by `Endocrine resistance` (`TP53`, `EGFR`), `Platinum drug resistance` (`TP53`, `BRCA1`), and `MAPK signaling pathway` (`TP53`, `NF1`).

Artifacts written by biocli:
- `results.jsonl`: per-gene JSONL envelopes with IDs, top pathways, top interaction partners, and top disease links.
- `summary.json` and `manifest.json`: run-level success counts, timings, cache stats, and artifact metadata.
- `methods.md` and `summary.csv`: human-readable methods summary and tabular run summary.
- `failures.jsonl`: empty for this successful batch.

Recovery note: one intermediate parse attempt treated `results.jsonl` as plain JSON and failed; I recovered by parsing each line as JSONL and used the parsed batch envelopes for the final structured record.

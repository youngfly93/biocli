# TP53 dossier run

Prepared a compact TP53 gene dossier without using `biocli`.

Evidence used:
- NCBI Gene TP53 page for the canonical human gene entity and stable IDs.
- Reactome TP53 transcriptional regulation pathway for pathway context.
- Reactome TP53-BID promoter binding event for a network/interaction clue.
- ClinVar TP53 NM_000546.6(TP53):c.742C>T (p.Arg248Trp) variation page for clinically relevant variant context.

Notes:
- No recovery was needed.
- The result is intentionally compact and source-linked for downstream use.

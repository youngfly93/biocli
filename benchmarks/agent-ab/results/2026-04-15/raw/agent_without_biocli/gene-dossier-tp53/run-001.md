# gene-dossier-tp53 / agent_without_biocli

Completed a black-box TP53 gene dossier without using `biocli`.

Sources used:
- NCBI Gene 7157 for canonical gene identity and functional summary
- ENCODE gene page for Ensembl/UniProt cross-reference
- KEGG K04451 for pathway context
- STRING TP53 network for the MDM2 interaction clue
- ClinVar Variation ID 233951 for clinically relevant variant context

Output written to `run-001.json`.
